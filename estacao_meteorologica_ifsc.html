Desenvolvimento do projeto

Funcionamento da estação

O sistema reúne componentes físicos e recursos computacionais para realizar as medições, processar as informações e armazená-las para consulta e análise.

1

Sensores

Realizam medições de variáveis como temperatura, umidade e pressão.

2

Raspberry Pi

Recebe as informações dos sensores e executa o processamento.

3

Banco de dados

Armazena as medições para consulta, organização e análise.

4

Visualização dos dados

Apresenta os dados de forma acessível para a comunidade.

Objetivo da instalação no campus

A estação permitirá obter dados das condições atmosféricas no próprio campus, contribuindo para o estudo do microclima local e para atividades de ensino, pesquisa e extensão.

Integração entre informática e meteorologia

O desenvolvimento envolve a integração de sensores ao Raspberry Pi, programação, organização dos registros em banco de dados e análise de informações meteorológicas.
